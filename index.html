Networking Tools

Discover powerful tools for network scanning, monitoring, and analysis.

Nmap

Network Mapper - Industry standard for network discovery and security auditing. Scan networks, discover hosts, and identify services.

Wireshark

World's foremost network protocol analyzer. Capture and interactively browse the traffic running on a computer network.

Netcat

The Swiss Army knife of networking tools. Read from and write to network connections using TCP or UDP.

Web Security Tools

Protect your web applications with comprehensive security testing tools.

Burp Suite

Integrated platform for performing security testing of web applications with extensive capabilities.

OWASP ZAP

Free, open-source web application security scanner that helps you automatically find security vulnerabilities.

SQLMap

Automated SQL injection and database takeover tool that helps detect and exploit SQL injection vulnerabilities.

Nikto

Web server scanner that performs comprehensive tests against web servers for multiple items.

DirBuster

Tool used to brute force directories and files names on web/application servers.

Wfuzz

Web application fuzzer that finds resources not linked through the provided application logic.

Password Cracking Tools

Powerful tools for recovering passwords through various techniques.

John the Ripper

Popular password cracker supporting many formats including Unix crypt, Windows LM hashes, and more.

Hashcat

Advanced password recovery utility that supports five unique modes of operation for over 200 highly-optimized hashing algorithms.

Hydra

Fast network login cracker which supports numerous protocols for attacking network authentication systems.

Cain & Abel

Windows-based password recovery tool that handles encrypted passwords, analyzing routing protocols, and more.

L0phtCrack

Password auditing and recovery tool that analyzes Windows and Unix password hashes.

Wireless & Mobile Tools

Tools for testing wireless networks and mobile applications.

Aircrack-ng

Suite of tools for auditing wireless networks, including packet capture and cracking capabilities.

Metasploit

Penetration testing framework with modules specifically designed for mobile application testing and exploitation.

WiFite

Automated wireless attack tool that combines the power of several other tools into one easy-to-use interface.

Android SDK

Software development kit for Android that includes tools for building and testing mobile applications.

Frida

Dynamic instrumentation toolkit for developers, reverse-engineers, and security researchers working with native apps.

Forensic Tools

Digital forensic tools for investigating cyber incidents and data recovery.

Autopsy

Open-source digital forensics platform built by Basis Technology that allows investigators to analyze disk images.

Volatility Framework

Memory forensics framework for incident response and malware analysis that works with memory dumps.

FTK Imager

Digital evidence imaging tool that creates perfect copies of digital media without making changes to the original evidence.

EnCase

Commercial digital forensic investigation software used for collecting and examining electronic evidence.

Cellebrite

Mobile device forensics solution that extracts data from smartphones and tablets for investigative purposes.
